# PSYHOZ VPN для Android

Kotlin, Android 10+ (arm64 и x86_64). Движок — Xray-core, туннель — hev-socks5-tunnel (готовые сборки из релизов).
Принимает только подписки с `psyholove.com.bot.nu`. Локальный SOCKS5 приложения: `127.0.0.1:10125` (на Android порты ниже 1024 недоступны приложениям без root, поэтому не 125).

## Сборка APK на Fedora
```
./build-apk.sh
```
Скрипт сам поставит JDK 17, Android SDK и Gradle, скачает Xray и tun2socks, создаст ключ подписи и соберёт
`PsyhozVPN-1.0.0.apk`. Первый раз 10–20 минут и ~2–3 ГБ на диске; повторные сборки — пара минут.

**Ключ подписи** лежит в `~/.psyhoz-android-build/` (`psyhoz.keystore`, `keystore.pass`). Сохрани копию:
обновить приложение у людей можно только APK, подписанным тем же ключом.

## Установка на телефон
Передай APK на телефон (Telegram, USB, облако), открой и разреши установку из этого источника.
Play Protect может предупредить о неизвестном разработчике: «Подробнее» → «Всё равно установить».

## Как это работает
- Xray запускается отдельным процессом (бинарник лежит как `libxray.so`) и слушает SOCKS5 на 127.0.0.1:10125.
- Системный VpnService создаёт интерфейс, hev-socks5-tunnel отправляет пакеты в этот SOCKS5.
- Само приложение исключено из VPN, поэтому Xray ходит к серверу напрямую, а TCP-пинг работает и при включённом VPN.
- Автоподключение при включении телефона — в настройках (⋮). IPv6 заворачивается в туннель (утечек нет).
- Лог Xray: `/data/data/com.psyhoz.vpn/files/run.log` (доступен через `adb run-as com.psyhoz.vpn cat files/run.log`).

## Ограничения
- Только 64-битные телефоны (arm64). 32-битные устройства не поддерживаются.
- Приложение не подписано в Google Play (только установка APK).
